# Recommender Systems

A collection of recommendation-system experiments and implementations, organized by approach. This repository is part of my learning and research portfolio in recommendation algorithms.

## Methods covered

- **Content-based recommendation** — recommendations based on item features or similarity.
- **Collaborative filtering** — user–item interaction based approaches.
- **Hybrid methods** — combining recommendation signals.
- **Learning to Rank** — a job recommendation example using LightGBM ranking.
- **Similarity-based recommenders** — simple baseline and similarity experiments.
- **Classic machine learning** — related experiments and supporting methods.
- **Research reproduction** — a TransGNN paper implementation is included under paper/TransGnn.

## Repository structure

| Folder | Contents |
|---|---|
| Classic ML/ | Classical machine learning experiments |
| Collaborative Base/ | Collaborative recommendation approaches |
| Hybird/ | Hybrid recommender experiments |
| Learning to Rank(LTR)/ | Job recommendation with LightGBM ranking |
| content based/ | Content-based recommendation |
| simple similarity recommender/ | Similarity-based baseline |
| paper/TransGnn/ | TransGNN research code |

## Getting started

The folders contain separate experiments, so requirements and data may differ between notebooks. Open the notebook or script in the chosen folder first and follow its data and dependency notes. Dataset files may need to be obtained separately.

## Research context

My Master's thesis focused on recommender systems using **Graph Neural Networks (GNNs)** and **Transformers**. This repository contains related experiments; it is not a claim that every method here was developed as part of the thesis.
